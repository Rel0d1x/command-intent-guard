# Command Intent Guard

Плагин для [Astra](https://github.com/mihailinl/AstraPlugins), который помогает
отличить произнесённую **команду** от **вопроса о похожем слове** —
например «поставь таймер» (команда) от «что такое таймер» (вопрос).

Дополняет соседний `whisper-stt-plus`, а не заменяет его — это два разных
плагина на разных уровнях:
- `whisper-stt-plus` (капабилити `stt`) правит ослышки распознавания речи —
  снэппинг «поставь тайфер» → «поставь таймер», когда фраза *искажена*.
- `command-intent-guard` (капабилити `tools`) разбирает НАМЕРЕНИЕ уже верно
  распознанной фразы — когда слова совпадают с командой дословно, но по
  смыслу это вопрос, а не инструкция.

## Как это устроено

В протоколе плагинов Astra нет хука, который перехватывал бы встроенное
сопоставление голосовой фразы с триггерами пользовательских команд — это
закрытая часть демона (см. `spec/hooks.yaml` в основном репозитории). Поэтому
плагин не пытается его подменить, а добавляет **tool** —
`classify_command_intent`, который модель (сама Астра) может вызвать сама,
когда сказанная фраза почти совпадает с триггером известной команды, но не
очевидно, команда это или вопрос об этом слове.

Классификация — эвристическая (без ML и без сети), основана на:
- вопросительных маркерах («что такое», «почему», конечный «?» и т.д.);
- командных глаголах повелительного наклонения («поставь», «включи», …);
- схожести фразы с триггером команды (расстояние Левенштейна).

Результат — `command` / `question` / `ambiguous` с уверенностью и коротким
объяснением, чтобы модель могла, например, переспросить пользователя при
`ambiguous`, а не выполнять команду молча.

## Установка

**Релиз, собранный и аттестованный GitHub Actions:**
[последний релиз](https://github.com/Rel0d1x/command-intent-guard/releases/latest) →
скачать `command-intent-guard-<версия>-windows-x64.astraplugin` (или
`linux-x64`) → в Astra Settings → Plugins → Install from file. Плагину нужна
только капабилити `tools`, так что все четыре высокорисковых права (тир 2)
для него и не запрашивались — Local Install ничего не режет.

```bash
astra-plugin verify command-intent-guard-0.1.0-windows-x64.astraplugin
gh attestation verify command-intent-guard-0.1.0-windows-x64.astraplugin --repo Rel0d1x/command-intent-guard
```

**Для разработки** — `astra-plugin dev .` (sideload, требует Developer Mode).

## Сборка

```bash
cargo build --release   # target\release\command_intent_guard.exe
cargo test               # логика классификации через Level-1 Harness
```

## Конфигурация (Astra → Plugins → Команда или вопрос?)

| Поле | По умолчанию | Смысл |
|---|---|---|
| `similarity_threshold` | 80 | Сходство (%) с триггером, выше которого фраза считается командой даже без явных маркеров |
| `extra_question_words` | `[]` | Свои слова-признаки вопроса, в дополнение к встроенным |
| `extra_command_words` | `[]` | Свои слова-признаки команды, в дополнение к встроенным |

## Ограничения v1

- Списки маркеров — русский + немного английского, вручную составленные;
  легко даёт ложные срабатывания на союзе «что» вне вопроса. Расширяйте
  через конфиг или правьте `QUESTION_MARKERS`/`COMMAND_MARKERS` в `src/main.rs`.
- Плагин не видит список команд пользователя напрямую (у `tools`-плагинов нет
  доступа к `CommandService` — он только для UI Astra), поэтому
  `command_name`/`trigger_phrase` должна передавать сама модель.
